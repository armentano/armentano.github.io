Abstract

The proposal of this work consists in the development of approaches for inferring team roles based on a classification derived from Belbin’s Team Roles, using machine learning techniques—a branch of Artificial Intelligence.

This proposal is aligned with the general objective of the project, which is to develop a tool that assists in the detection of roles. Additionally, through the analysis of each student’s behavior based on Belbin’s theory, the tool will enable the automatic formation of efficient groups.

The chosen collaborative work environment for developing this project involves various applications within the Google platform. These include Hangouts, a communication tool that users will use to interact and discuss the tasks at hand, and Google Docs, a word processor that allows multiple users to work simultaneously, fostering online collaboration.

On one hand, data will be collected from various group chat sessions through conversation analysis. On the other hand, prior to engaging in collaborative work, users will complete surveys based on the SYMLOG model of group analysis. This model proposes a classification of key personality factors that impact group performance and provides tools for measuring them. The results reveal the presence of traits relevant to group dynamics, which can be directly linked to Belbin’s Team Roles. This relationship will offer an initial view of the roles as self-perceived by the users.

All the collected information will be analyzed using artificial intelligence techniques, applying strategies to develop an approach that can efficiently classify user roles.
