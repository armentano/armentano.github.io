Abstract

Sentiment identification in text is a significant field of study (opinion mining – sentiment analysis), with social media platforms like Twitter attracting the interest of researchers in language processing as well as in political and social sciences. The task typically involves detecting whether a text expresses a positive, negative, or neutral sentiment. Sentiment can be general or directed toward a specific topic, such as a person, a product, or an event.

In this context, we present a web application that interacts with Twitter and is intended for a wide range of users, as it can be used both for recreational and entertainment purposes, as well as to analyze social media responses to a product or service from a particular company or organization.

This application allows users to collect tweets based on different search criteria: keyword (hashtag), replies to a given tweet, or tweets from a specific user. It then provides the ability to analyze the sentiment of this set of opinions using various algorithms:

  • Machine Learning: The application includes an algorithm that has been trained on an extensive dataset of tweets labeled as positive, negative, or neutral.
  • Grammatical Structures: The underlying technology of this algorithm is based on a new type of recursive neural network that relies on grammatical structures. It is the only model capable of accurately capturing the effects of negation and its scope within positive and negative phrases.

Finally, the application presents a graphical and interactive framework where users can navigate through the data and perform a detailed analysis of the information obtained. This was implemented using a Business Intelligence tool.
