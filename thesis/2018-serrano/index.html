Abstract

The proposal made in this thesis consisted of the development of a framework to facilitate the generation of collaborative user profiles, following the SYMLOG model, based on their interactions within a given shared space. This profile generation was carried out using deep learning techniques, specifically through the application of various concepts inherent to neural networks. Several neural network concepts were experimented with, which were then integrated into a single model in order to maximize the accuracy of the generated profiles.

To validate the generated profiles, four deep learning approaches were evaluated, each varying in the concepts they employed. The first approach primarily used dense layers in the neural network architecture; the second utilized convolutional layers; and the third relied on recurrent operations. Finally, the fourth approach combined the best aspects of these concepts to create a hybrid neural network architecture that improved upon the metrics achieved by the previous approaches.

In addition to the framework, a web application was implemented to graphically organize the information obtained. In this way, the use of such tools was made more accessible to users with minimal knowledge of these types of systems. Since the framework was designed to function as a backend, the information it provided was displayed on the client side through various graphs and tables. This approach facilitated understanding, avoiding the need to interpret formats such as JSON or CSV.

The process of building collaborative profiles began with a set of messages from the dialogue generated by group members working collaboratively to solve a common task. These messages were processed by the neural network models to categorize each one of them according to the IPA method. Based on these categories, correspondences were established between the IPA method and SYMLOG. That is, a mapping was performed from the categorizations obtained by the networks to the corresponding trinomial of each dimension in the SYMLOG model.
