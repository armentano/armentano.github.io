Intention Recognition for the Organizational Memory

Jun 1, 2012
Intention Recognition Machine Learning Webmining

Appropriately managing an organization’s knowledge is crucial because a significant portion of it is volatile, as it resides within individuals. This phenomenon leads to what is known as corporate amnesia, a problem characterized by the regular loss of organizational knowledge and experience. The collection of this knowledge and experience, which defines the way an organization operates, is referred to as Organizational Memory.

In its essence, organizational memory consists of the organization’s documentation and the objects or artifacts stored in the corporate library or electronic database, which can be accessed by employees familiar with the organization’s specific events and experiences. Both explicit knowledge (physical evidence) and implicit knowledge (more abstract, mental evidence) are essential for effective decision-making, learning from past experiences, and striving to replicate successful situations while avoiding past mistakes.

The objective of this project is to analyze, design, and implement techniques that enable the semi-automatic generation of a model of the activities carried out by an organization’s employees. This model will allow for tracking ongoing activities at any given moment and identifying employee behaviors that deviate from typical patterns.

To achieve this, the project proposes the definition, implementation, and evaluation of new intelligent recommendation methods and techniques that provide active assistance to employees whose behavior does not align with expected patterns. We propose a learning algorithm based on Variable-Order Markov Models that will acquire a model of the intentions an employee may have within the organization. This algorithm will be based on observing the tasks an employee performs and the intentions motivating those tasks.

The learning algorithm will construct a model of the tasks necessary to achieve various objectives within the organization, ensuring that this knowledge persists within the company, thereby contributing to its organizational memory. This model will then be used to detect an employee’s intention at a given moment and identify deviations from expected behavior.

A Variable Order Markov Model for Architecture Conformance Checking

Guillermo Rodriguez, Marcelo Gabriel Armentano, Alvaro Soria, Emilio Corengia
March 2020 Electronic Journal of Informatics and Operations Research
Conformance between architecture and implementation is a key aspect of architecture-centric development. However, the architecture as documented and the architecture as implemented tend to diverge from each other over time. Thus, conformance checks should be run periodically on the system in order to detect and correct differences. Despite having a structural conformance analysis, assessing whether the main scenarios describing the architectural behavior are faithfully implemented in the code is still challenging. Checking conformance to architectural scenarios is usually a time-consuming and error-prone activity. In this article, we describe ArchLearner, a tool to assist architects to bridge the gap between architecture and its implementation. The architecture is specified with Use-Case Maps (UCMs), a notation for modeling both high-level structure and behavior. ArchLearner uses Markov Models to detect code deviations with respect to predetermined UCMs, based on the analysis of system execution traces for those UCMs. The results from two case-studies have shown that ArchLearner is practical and reduces conformance checking efforts.
