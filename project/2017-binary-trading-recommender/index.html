Recommender System for Decision-Making in Binary Options Trading

Dec 1, 2017
Recommender Systems Machine Learning

Platforms for binary options trading and long-term stock trading are abundant in the market. However, there is no intelligent adjustment operation for binary options based on a community model of users grouped under social network models. Similarly, there are no platforms on the market with bots for short-term volatility placement or user grouping to analyze behavior using social graph methods.

This project aims to develop a prototype algorithm to analyze the specific market conditions of binary options and trading based on the concept of short-term volatility. In both cases, the algorithm will be capable of predicting how to invest efficiently within an active and identified community.
