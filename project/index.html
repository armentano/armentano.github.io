Projects

Online Harm-Aware Recommendation Systems in Social Networks

This project focuses on defining new algorithms and recommendation systems aimed at mitigating the negative effects of harmful online content.

Intelligent urban mobility through crowdsensing

This project aims to generate value-added information from data sensed about the individual mobility of citizens, with the goal of improving collective mobility.

Intelligent Advertisement Recommendation for an Online Sales Platform Based on Implicit User Preference Acquisition and Geospatial Conditions

The project aims to develop a prototype that connects buyers and sellers through an intelligent characterization of each user, considering their short-term preferences and defining geospatial characteristics.

Analysis and Traceability of the Spread of the COVID-19 Virus Through Mobile Devices

The objective of the project is to develop a platform that supports a georeferenced social network for the epidemiological tracking of the COVID-19 pandemic.

Recommender System for Decision-Making in Binary Options Trading

This project aims to develop a prototype algorithm to analyze the specific market conditions of binary options and trading based on the concept of short-term volatility.

Design and Development of Group Recommendation Systems with a Multi-Agent Approach

The project explore techniques and architectures for designing and developing GRS applications that enable the reuse of software assets and the analysis of emerging quality attributes of such applications.

Social Network Mining for User Recommendation

The overall objective of this project is to specify, adapt, and apply techniques for identifying and recommending users with relevant characteristics to other users within the network.

User Profiles for Intelligent Assistance in Computer-Supported Collaborative Work

We propose the automatic construction of user profiles in collaborative work systems based on the observation of their interactions with the system and their teammates, with the aim of forming more efficient and productive work groups.

Intention Recognition for Assisting Users on the Web

This project aims to study mechanisms for detecting user intentions to provide proactive assistance that helps users achieve their goals.

Intention Recognition for the Organizational Memory

The objective of this project is to analyze, design, and implement techniques that enable the semi-automatic generation of a model of the activities carried out by an organization's employees.
